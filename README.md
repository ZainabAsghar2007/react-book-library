# 📚 Book Library Explorer

A modern React web application built to search, sort, and explore books seamlessly by integrating external book library APIs with a clean, responsive Material-UI interface.

## ✨ Features

- **🔍 Advanced Book Search**: Search books dynamically by title, author, or keywords.
- **📊 Sorting Options**: Sort results by relevance, newest, oldest, or most editions.
- **📱 Responsive Grid UI**: Built with Material-UI (`Grid`, `Container`, `Card`) for a seamless layout across mobile, tablet, and desktop screens.
- **📄 Pagination**: Navigate through extensive search results cleanly with dynamic page counting.
- **🔗 URL Synchronization**: Keeps search queries and states synchronized with URL parameters for easy sharing and bookmarking.
- **⚡ Error & Loading States**: Elegant feedback loops including loading spinners and error alerts.

## 🛠️ Tech Stack

- **Frontend**: React, React Router DOM
- **UI Library**: Material-UI (MUI)
- **API Integration**: Asynchronous REST API fetching
- **Version Control**: Git & GitHub

## 🚀 Getting Started

To run this project locally, follow these steps:

### 📋 Prerequisites

Make sure you have Node.js installed on your system.

### 💻 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ZainabAsghar2007/react-book-library.git

2. **Navigate to the project directory:**
   ```bash
   cd book-library

3. **Install dependencies:**
   ```bash
   npm install

4. **Start the development server:**
   ```bash
   npm run dev
   
Open your browser and navigate to http://localhost:5173 to view the app.
